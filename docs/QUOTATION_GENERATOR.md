# GEO 报价单生成服务

## 目标

运营人员只需提供品牌名称和品牌方目标词 `.xlsx`，即可生成可直接下载的 GEO 验证服务
报价单 `.docx`。输出的版心、表格、字号、页眉页脚、商务条款和章节顺序由程序固定；模型
只负责行业画像、代表词选择和 Query 语义变体，不能改写合同口径或 Word 样式。

参考样例：

- 输入：`client-sbaq/硅基守望-盛邦安全目标词.xlsx`
- 输出参考：`client-sbaq/报价单-盛邦-final(2).docx`
- 参考版式：A4、上下边距 18 mm、左右边距 15 mm、保密页眉、居中页码；盛邦回归为 6 页

## 模板与品牌变量边界

| 内容                                     | 处理方式           | 说明                                                                             |
| ---------------------------------------- | ------------------ | -------------------------------------------------------------------------------- |
| 标题、出具公司、报价有效期               | 固定模板           | 出具公司为北京硅基守望科技有限公司，有效期为 30 个工作日                         |
| 四项服务、执行参数、指标定义             | 固定模板           | 3 个问题 × 3 组变体、3 个平台、2 个地域、每题重复 2 次等口径不交给模型           |
| 商务条款、保密条款、页眉                 | 固定模板           | 逐字固定，避免生成式改写造成合同语义漂移                                         |
| A4 版心、字体字号、表格、页码            | 固定模板           | renderer 显式设置，不依赖模型输出                                                |
| SEC 方法论和两条文献                     | 固定框架           | 行业类别、SEC 类型及画像段落随品牌变化                                           |
| 品牌名、报价日期、文件名                 | 品牌变量           | 日期缺省按 `Asia/Shanghai` 当日生成                                              |
| Excel 分组和原始目标词                   | 品牌变量、原文回绑 | 模型只返回 `source_id`；附录二原文始终从上传文件取值，不能被模型篡改             |
| 附录二代表问题                           | 品牌变量           | 最多 18 条，按分组轮转分配配额；五组时为 4/4/4/3/3                               |
| A/B/C 语义变体                           | 品牌变量           | A 正式换述、B 换角度、C 口语化，三条必须相关且互不重复                           |
| 附录三机会词与优化 Query                 | 品牌变量           | 结合公开品牌信息和现有目标词生成 16 条相邻机会；统一标为“拟新增”，不冒充客户原词 |
| 价格、报价人签字                         | 暂留空             | 示例本身为空；仅凭品牌名和目标词无法确定商务价格                                 |
| 推荐次数、提升比例、品牌是否进入推荐名单 | 不可由当前输入推导 | 必须来自真实平台采样；当前报价单明确写“待实测”，禁止模型编造                     |

示例附录一中的 `DeepSeek/文心一言` 推荐次数、`4→37` 以及“盛邦安全未进入推荐名单”是
一次具体测试的结果，不是通用模板。当前两项输入没有对应采样证据，因此服务保留效果验证
表格和验证口径，但不会复制这些数字。未来若接入正式采样事实，应新增结构化实测数据输入，
经证据绑定后再填充该区域。

## 生成流程

1. 安全检查 XLSX 压缩包、路径、体积和 XML，读取所有可见工作表。
2. 自动识别“产线 / 分类 / 关键问题 / 目标词”等常见表头，保留工作簿分组顺序并去重。
3. 对原始词分配附录二名额；模型只能在指定分组配额内选择已存在的 `source_id`。
4. 使用既有 `GEO_RESEARCH_LLM_*` 配置联网核对品牌业务方向，生成受约束 JSON。
5. 校验数量、来源 ID、分组配额、文本长度、变体去重和未经验证的效果数字。
6. 由确定性 renderer 生成 DOCX，并返回文件 SHA-256 与各类 Query 数量响应头。

## 运营端一键生成

运营或管理员登录后访问：

```text
/platform/operations/quotations
```

填写品牌名称、报价日期并选择目标词 XLSX，点击“生成并下载 DOCX”即可。浏览器不会接触
模型 Key；请求仍由后端读取受保护的 `GEO_RESEARCH_LLM_*` 生产配置。下载前，前端会再次
校验响应 MIME、DOCX ZIP 签名、文件体积、响应计数和 `X-Quotation-SHA256`，校验失败时
不下载文档。审核员账号只读，不具备生成权限。

## HTTP API

内部运营接口（需要 `project:write` 权限）：

```text
POST /api/v2/quotations/generate
Content-Type: multipart/form-data
```

字段：

- `brand_name`：必填，2–80 字符。
- `target_words`：必填，`.xlsx`，单文件最大 10 MiB，最多读取 300 条去重目标词。
- `quote_date`：可选，`YYYY-MM-DD`；缺省为上海时区当日。
- `model`：可选，必须位于 `GEO_RESEARCH_LLM_MODELS` 允许清单。

示例：

```bash
curl -X POST 'https://HOST/api/v2/quotations/generate' \
  -H 'Authorization: Bearer ...' \
  -F 'brand_name=盛邦安全' \
  -F 'quote_date=2026-08-10' \
  -F 'target_words=@../client-sbaq/硅基守望-盛邦安全目标词.xlsx' \
  --output '报价单-盛邦安全-20260810.docx'
```

成功响应为 DOCX，并包含：

- `X-Quotation-Target-Query-Count`
- `X-Quotation-Selected-Query-Count`
- `X-Quotation-Opportunity-Count`
- `X-Quotation-SHA256`
- `Cache-Control: no-store`

未配置 `GEO_RESEARCH_LLM_API_KEY` 时返回 `503 llm_disabled`；模型输出未通过内容契约时
返回 `502 quotation_generation_failed`，不会降级为低质量或伪造文案。

## 命令行一键生成

在 `platform-v2` 目录执行：

```bash
.venv/bin/python tools/generate_quotation.py \
  --brand '盛邦安全' \
  --target-words '../client-sbaq/硅基守望-盛邦安全目标词.xlsx' \
  --quote-date 2026-08-10 \
  --output '../client-sbaq/报价单-盛邦安全-20260810.docx'
```

输出已存在时默认拒绝覆盖；明确需要覆盖时加 `--force`。

## Excel 约定

推荐沿用样例的两列格式：A 列为序号，B 列为目标词；每个分组前放置
`序号 / 某某线-关键问题`。服务也支持常见的 `分类 / 目标词` 表头和单列目标词。公式单元格
不会执行，也不会作为目标词读取。

## 版式验证

单元测试检查 A4 尺寸、18/15 mm 页边距、6×4 服务表、保密页眉、动态页码字段、三份附录、
“待实测”措辞和无虚构推荐次数。盛邦样例另经 LibreOffice 实际渲染为 PDF 回归，章节分页为
`1 + 1 + 2 + 2 = 6` 页。由于其他品牌的 Query 长度不同，最终页数允许自然增加，但标题、
表格和单条 Query 区块不会改变模板层级。
