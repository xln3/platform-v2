# 测量手机配置说明（短信自动转发 + 人工接码）

> 目标：任何人 5 分钟配好一台测量手机，让测评平台的验证码短信自动进 GEO 系统；采集/开户撞到图形验证码时，能在手机上人工接管。
>
> 配置页本身就是在机向导，手机浏览器打开：**https://39.105.175.14:8443/api/v2/otp/setup**
> 本文是该向导的要点与实测坑浓缩；细节冲突时以页面为准。
>
> 需要准备：① 一台能上网的安卓测量手机；② 管理密码（operator token，找运维要）。

## 0. 先判断你的场景

| 场景 | 要做的事 |
|---|---|
| 新手机 + 新号码 | 第 1～5 步全走 |
| 新手机（老号码换机） | 第 1～5 步全走，备注填老号 |
| 老手机 + 新号码 | 只做第 2 步 + 第 5 步（通道/规则与号码无关，不用动） |
| 采集/开户撞到图形验证码（滑块等） | 不用提前设置什么——系统会推方糖消息找你，见「二、人工接码」 |

## 一、短信自动转发（SmsForwarder）

全程照配置页逐步执行；下面只标每步要点和实测踩过的坑。

1. **第 0 步 · 防杀（最容易翻车，务必逐条做）**
   - 系统设置 → 应用管理 → SmsForwarder：省电策略 = 无限制、开自启动、最近任务卡片下拉锁定；短信/通知权限授予。
   - **SmsForwarder → 通用设置 → 免打扰(禁用转发)时间段 = `00:00 ~ 00:00`**。起止相等 = 该功能停用；20260810 实测被设成 `00:00 ~ 24:00`（= 全天禁转发），一条都发不出。
2. **第 1 步 · 安装**：页面内下载 APK（v3.5.0，服务器自托管）。已装过可跳过。
3. **第 2 步 · 卡槽备注 + 号码入册**：
   - SmsForwarder → 通用设置 → 个性设置 →「SIM1主键/备注」「SIM2主键/备注」的备注框，填**含该卡真实号码**的文本（App 提示格式 `运营商_手机号`，如 `中国移动_18810936058`）。服务端靠号码反解归属，不靠机身标识。
   - 新号码先在页面「注册新号码」入册（需先在页面底部输管理密码解锁）：填 11 位号码，卡槽/运营商选填；注册成功即自动复制备注，粘贴进上面对应 SIM 的备注框。入册后任何装机页刷新都能拉到这条备注。
4. **第 3 步 · 发送通道（Webhook）**：照页面逐格复制/选择（Webhook Server、消息模板、Headers 的 token 值解锁后显示）。两个实测坑：
   - **消息模板必须与复制值逐字符一致**——多一个 `"` 服务端就归不了号（码不丢，但落 unrouted，查码按号查不到）。
   - v3.5.0 没有「忽略 SSL 证书」开关，不用找（旧文档里那条已废止）。
5. **第 4 步 · 转发规则**：照页面逐格。白名单只放行测评/媒体平台短信；银行、支付等隐私短信不匹配、不转发、不出本机——切勿把规则泛化成「所有验证码」。
6. **第 5 步 · 验证**：用另一台手机给测量号发一条含「豆包」的短信；页面点「查看最近推送」能看到它（手机号掩码 + 码长 + 平台）= 全链路通。通道页的【测试】按钮也可自检发送通道。

## 二、人工接码（图形验证码人工接管，方糖推送）

**是什么**：采集或开户途中撞到图形验证码（拖滑块、点选文字等）时，系统会**自动挂起任务**，同时通过**方糖**（Server酱·Turbo）把一条接管链接推到运维的微信——不用人盯系统，收到推送再动手，全程约 30 秒。

**首次使用，先配一次推送（收码的人做一遍即可）**：

1. 微信关注「Server酱·Turbo」公众号（方糖），按号内指引拿到自己的 SendKey。
2. 把 SendKey 发给运维，由运维配进服务器推送通道（约 1 分钟）。
3. 已经能收到推送的手机，跳过本步。

**收到推送后**：

1. 微信里点开方糖消息 → 点里面的接管链接。
2. 手机页面显示服务器上平台页面的**实时画面**——照画面把图形验证做完（拖滑块/点选），只动验证码本身，页面上其他按钮、链接都不要点。
3. 点页面底部「**我已完成，继续采集**」→ 显示「已解决，采集已自动恢复」即结束：系统自动断点续跑，不用再做任何操作。

**注意**：

- 接管链接一次性、有时效（约 1 小时），收到请尽快处理；同一任务最多接管 3 次，都超时则任务按失败计。
- 开户类接管（运维手动发起的会话）页面上的完成按钮无效——运维说一声「好了」才算完。
- 收不到方糖推送：找运维确认 SendKey 是否已配上。

## 三、速查与排障

| 症状 | 原因（实测案例） | 处置 |
|---|---|---|
| 全天零推送 | 全局免打扰 ≠ 00:00~00:00（20260810） | 通用设置改回 `00:00 ~ 00:00` |
| 推送到达但系统查不到码 | 消息模板被改坏（多一个引号，20260810） | 与页面复制值逐字符对齐 |
| 时而收不到、重启 App 就好 | 国产 ROM 杀后台（20260807） | 重做第 0 步防杀 |
| 页面复制的 Webhook 地址没有 8443 端口 | 反代丢端口，已修复（20260810） | 刷新页面重新复制 |
| 找不到「忽略 SSL 证书」开关 | v3.5.0 没有此开关 | 正常，不用找 |
| 收不到方糖接管推送 | SendKey 未配/推送通道未配 | 找运维确认配置 |

运维需要的服务端细节（端点、token、工具用法）不在本文——见 `api/geo_platform/otp/router.py` 与 `tools/otp_assist_login.py` 的 docstring。
