## 开源实现对照

- [Self-RAG 作者代码](https://github.com/AkariAsai/self-rag)和 [DynamicER 作者代码](https://github.com/jiny1623/DynamicER)分别覆盖运行时自检和动态 mention 解析，可以作为模型与实体解析基线，不能替代知识审核与发布。
- [Graphiti](https://github.com/getzep/graphiti)持续把 episode 整合为有来源和有效时间的知识图谱，保留 `valid_at/invalid_at` 历史；它与本任务的时间化关系表达非常接近，但仓库本身不等于四眼审批、跨客户脱敏聚合、候选 release 回放和静态外部源三方发布流程。
- [Mem0](https://github.com/mem0ai/mem0)实现从交互提取、更新和检索 memory，并可用实体图增强召回；其目标主要是 agent/user memory，不应被当作经公共证据审核的跨应用事实库。
- [ERASE 论文资源](https://aclanthology.org/2025.findings-naacl.168/)和 [STACKFEED 论文资源](https://aclanthology.org/2025.emnlp-industry.176/)是“新增文档时编辑旧知识”和“专家反馈改 KB”的强基线。后续实验必须直接比较，不能只比较静态 RAG。

## 品牌分类与竞品判断的研究依据

- [Rosch 与 Mervis 的家族相似性研究](https://www.sciencedirect.com/science/article/pii/0010028575900249)说明品类不是只靠一个名称或单一属性形成；文字相似不能直接推出同一对象或竞品。
- [Aaker 与 Joachimsthaler 的 brand relationship spectrum](https://journals.sagepub.com/doi/abs/10.1177/000812560004200401)区分 branded house、sub-brand、endorsed brand 和 house of brands 等关系，支持把集团、品牌家族、子品牌与产品分别表达。
- [Hauser 与 Wernerfelt](https://academic.oup.com/jcr/article/16/4/393/1787720)以及 [Nedungadi](https://academic.oup.com/jcr/article-abstract/17/3/263/1822527)把可知集合、回忆和实际 consideration set 分开，支持“身份归属”和“当前场景是否竞品”分开判断。
- [Aaker 与 Keller 的品牌延伸研究](https://journals.sagepub.com/doi/pdf/10.1177/002224299005400102)说明消费者对延伸的评价取决于感知匹配和母品牌联想；不能因为母品牌相同就在所有品类合并计权。

## 工程贡献与研究问题的边界

已经实现的是一组生产工程约束：本地优先读取、四种模型策略、严格结构输出、幂等观察、证据与反证、四眼审核、不可变版本、三方对账、回滚、脱敏跨应用聚合，以及品牌身份/汇总/竞品资格分离。这些部件在既有研究和知识管理系统中都有先例；把它们组合并可靠运行是工程贡献，不自动成为论文创新。

以下仍只是待验证研究问题：

1. 带任务、行业、地域、受众、时间和反例的断言，是否比无条件关系更少跨场景误用。
2. 候选版本发布前回放历史任务，是否比直接追加、模型写入或专家编辑更少制造新错误。
3. 在相同人工审核时间下，综合来源质量、跨项目一致性、模型分歧、稳定性、影响范围和回放结果，是否能降低错误发布率并保持覆盖率。
4. 不保存客户原文时，脱敏摘要、统计与不可逆引用各自还能保留多少新知识发现价值。

要支持研究结论，实验必须按时间切分，比较静态 RAG、只追加文档、LLM 直接改知识、专家反馈、WriteBack-RAG 类证据提炼、DynamicER 类新名称解析和本项目策略；还要移除适用条件、历史回放、反对证据、跨项目聚合、多模型及人工审核做消融，并报告置信区间或显著性。当前生产测试不能替代这些实验。若强基线更好，应报告负结果，而不是重新命名方法。

具体的时间切分、七组实现合同、已执行结果和未执行项见 `EXPERIMENT_PROTOCOL.md`。本轮已在统一的 22 条读取模型上运行七个工程类比，包括一次真实 LLM direct patch，并执行六项移除 proxy、10,000 次配对 bootstrap 和精确 McNemar 检验。但专家、WriteBack-RAG、DynamicER 和传统 RAG 行都不是作者流程复现，金标也不是独立 held-out；研究问题一只有小集信号，研究二同时出现“真实回放拦住 `.5`”和“22 条小集移除回放仍不退化”的混合结果，研究三、四仍没有受控结论。四个问题都没有达到论文创新或优越性声明标准。
